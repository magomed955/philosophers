# Philosophers

Philosophers is a project developed as part of the 42 curriculum that consists of solving the Dining Philosophers problem to explore concurrency and synchronization. The project simulates philosophers sitting around a table, alternating between eating, thinking, and sleeping while sharing limited resources. It focuses on multithreading, mutexes, race condition prevention, and synchronization to ensure safe and efficient execution.

**Technologies:** C, POSIX Threads (pthreads), Mutexes, Concurrency, Makefile, Git.
